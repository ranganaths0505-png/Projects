# Project 02 - Product Performance Analysis

## Objective

Analyze product sales data to identify top-performing products, sales quantities, category performance, and revenue trends.

## Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed

- Product-wise revenue analysis
- Product-wise quantity analysis
- Category-wise revenue analysis
- Daily sales analysis
- Identification of highest-revenue products
- Identification of highest-quantity products
- Visualization of sales performance

## Dataset

The project uses `data/sales_data.csv`.
